# Findings Log

Newest first. One block per find, logged the moment it happens (capture running). Full workflow in `docs/CONTENT_PIPELINE.md`, section 2; clip naming in the "Clip naming" section there.

## Template (copy this block under today's date heading in "Log")

```markdown
### HH:MM (your time zone) — <what, in a few words>
- **What:** <the finding, one or two sentences; exact names, numbers, $ amounts>
- **Where:** <region / landmark / mission; map x,y if you noted it>
- **How verified:** <seen once | repeated N times | on a second save | on both PS5 and Xbox>
- **Clip:** raw/2026-11-19/clip-###.mp4 @ mm:ss (screenshot: raw/2026-11-19/shot-###.png)
- **Page to update:** /<url>/ (or "new guide: <title>")
- **Status to use:** confirmed (we saw it) | unverified (seen once, needs a retest)
- **Done:** [ ] page updated  [ ] map pin / checklist entry  [ ] Short
```

Keep story out of this log too: write "early story mission" rather than a mission name, and no story beats.

New page from a finding: `npm run new:guide -- "GTA 6: How to …"` (add `--hub money` etc.) or `npm run new:news -- "Headline"`. Both start as `draft: true`.
